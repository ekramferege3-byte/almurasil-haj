# almurasil-haj
A multi-language mobile app (Amharic, English, turkey , Arabic ) designed to guide and assist haji pilgrims with voice and health features
Almurasil-Haj (المراسل الحاج) 🕋
A Cross-Platform Mobile Application for Hajj Pilgrims
🌟 Project Overview
Almurasil-Haj is a specialized mobile application developed to assist and guide Hajj pilgrims from diverse linguistic backgrounds. The app focuses on providing real-time guidance, health monitoring, and voice-assisted navigation to ensure a safe and spiritual journey for the global Muslim community (Ummah).
🚀 Key Features
Multi-Language Support: Seamlessly switch between Amharic, Arabic, Turkish, and English.
Voice Guidance: Integrated voice features to help elderly or visually impaired pilgrims navigate the Hajj rituals.
Health Tracking: Features designed to monitor pilgrim health and provide emergency contacts.
User-Centric Design: A clean, intuitive UI built for high-stress, crowded environments.
🛠️ Technical Stack
Framework: Flutter (Cross-platform)
Language: Dart
Localization: custom i18n logic for multi-script support (Ge'ez and Arabic).
State Management: Provider/Riverpod (for handling language and user health data).
